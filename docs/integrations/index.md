# Integrations

Ready-made connections between Bizmitra and the software you already use. Switch one on, and your data moves between systems without anyone writing code.

::: info Documentation in progress
Integration guides are being written and will be published here as each one becomes available.

In the meantime, [contact Bizmitra](https://bizmitra.io/contact) to ask about a specific integration.
:::

## How these differ from the Developer Platform

Both live in these docs, and they are easy to confuse. The difference is who does the building.

| | Integrations | [Developer Platform](/developer/) |
|---|---|---|
| **Who builds it** | Bizmitra | You |
| **Who it is for** | Businesses using the software | Engineers and SaaS companies |
| **Setup** | Configuration, no code | An integration you write |
| **Flexibility** | What the integration supports | Whatever you build |

If you run a business and want your online store's orders to appear in your accounts, you want an integration.

If you are building a product and want your customers to connect *their* accounting data to it, you want the [Developer Platform](/developer/).

## Requesting one

If the software you use is not listed, [tell Bizmitra](https://bizmitra.io/contact). Which integrations get built is driven substantially by what customers ask for.

If you have engineering capability in-house, the [Developer Platform](/developer/) lets you build the connection yourself against the same underlying APIs.
